HOW TO USE — approved data export (the REAL data path)
======================================================

Deal DNA analyzes APPROVED sales-call evidence connected to read-only Salesforce outcomes.
It does NOT fetch from a live connector and does NOT fabricate real data.

To run on real, approved data:

1) In your approved environment, export approved transcripts from the SharePoint folder:
     /teams/Q3AIHackathon/Shared Documents/Deal DNA_ The Win-Loss Decoder for Sales/Transcripts/
   Save each call as .txt or .vtt (speaker-attributed, timestamped).

2) Place them here, one folder per sales cycle:
     data/approved_exports/transcripts/<cycle_id>/<call_id>.vtt   (or .txt)
     data/approved_exports/transcripts/<cycle_id>/<call_id>.metadata.json
   metadata.json should include: cycle_id, call_id, opportunity_id, account, call_date,
   source_system, source_url, product, stage, consent, transcript_status.

3) Export read-only Salesforce outcomes to:
     data/approved_exports/salesforce/opportunities.csv
   Columns: opportunity_id, account, product_family, stage, IsWon, outcome, owner, close_date, sale_type
   (Qualify new sales at the OpportunityLineItem level: Sale_Type__c = 'New'.)

4) Ingest:
     python -m deal_dna.run --ingest

The app/CLI will show "Data: Approved export". Consent, source_url, and transcript_status are
preserved so every finding stays traceable. If this folder is empty, a clearly-labeled SYNTHETIC
demo set is used instead.

DO NOT commit real customer transcripts, recordings, or credentials to any repository.
